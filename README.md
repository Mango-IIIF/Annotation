# @mango-iiif/annotation

Annotorious and OpenSeadragon annotation editor with the Mango Svelte sidebar.

The package provides a small Annotorious facade and the drawing toolbar and
intent-first sidebar used by `@mango-iiif/annotate`.

## Install

```sh
npm install @mango-iiif/annotation @annotorious/openseadragon openseadragon svelte
```

## API

See [API.md](./API.md).

## Development

```sh
npm run dev
npm run typecheck
npm test
npm run build
```
